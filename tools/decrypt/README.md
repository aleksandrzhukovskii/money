# money-decrypt

Decrypts a Money Tracker backup into a plain SQLite file, on a machine you control.

The app deliberately has no "Export Plain" button. An unencrypted copy of your
finances shouldn't land in a browser download folder that syncs to a cloud drive —
so the plaintext export lives here instead, where you decide where the file goes.

## Build

```sh
cd tools/decrypt
go build -o money-decrypt .
```

Requires Go 1.24+ (for the standard library's `crypto/pbkdf2`). No dependencies.

## Use

The password is read from `$MONEY_PASSWORD`, or from stdin if that's unset.

```sh
# Decrypt a backup exported from Settings -> Export Encrypted
MONEY_PASSWORD='...' ./money-decrypt money-tracker-2026-09-05.enc
# -> money-tracker-2026-09-05.db

# Keep the password out of your shell history and environment
read -rs PW && echo "$PW" | ./money-decrypt -out finances.db money-tracker.enc

# Inspect it
sqlite3 finances.db 'SELECT type, date, amount, comment FROM transactions LIMIT 10;'
```

You can decrypt the file the app syncs to GitHub the same way — download
`money-tracker.enc` from the private repo and point the tool at it.

To recover the GitHub token if you still know the password, copy the
`money-tracker-credentials` value out of the browser's localStorage into a file
and pass `-base64`; it decrypts to JSON:

```sh
MONEY_PASSWORD='...' ./money-decrypt -base64 credentials.txt
```

### Flags

| Flag | Meaning |
|---|---|
| `-out` | Output path, `-` for stdout. Defaults to the input with a `.db` extension. |
| `-f` | Overwrite the output file if it already exists. |
| `-iter` | PBKDF2 iteration count (default 100000). Needed if the app's KDF changes. |
| `-base64` | Treat the input as base64 — for the localStorage credentials blob. |

## Format

Matches `src/lib/crypto.ts`:

```
salt (16 bytes) || nonce (12 bytes) || AES-256-GCM ciphertext+tag
key = PBKDF2-HMAC-SHA256(password, salt, 100000) -> 32 bytes
```

`main_test.go` decrypts a fixture generated by the browser implementation, so the
tests fail if the two ever drift apart. If the app's format gains a version
header, add the parsing here and regenerate that fixture.

```sh
go test ./...
```
